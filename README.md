# 🥊 Jai Rak Team

### Muito além do Muay Thai. Uma missão de amor, disciplina e fé.

O **Jai Rak Team** é um projeto social cristão que utiliza o Muay Thai como ferramenta de acolhimento, desenvolvimento pessoal e transformação social de crianças e adolescentes.

Mais do que ensinar uma arte marcial, o projeto busca transmitir valores como respeito, disciplina, responsabilidade e perseverança, tendo o amor de Jesus Cristo como fundamento de sua missão.

Este repositório contém o código-fonte do site institucional do Jai Rak Team, desenvolvido para apresentar o projeto, divulgar suas atividades e facilitar o contato com participantes e apoiadores.

---

## ❤️ Sobre o projeto

O nome **Jai Rak** foi escolhido para representar a ideia de *coração de amor*, associada à língua tailandesa.

Acreditamos que o esporte pode abrir portas, fortalecer vínculos e oferecer referências positivas para crianças e adolescentes.

No Jai Rak Team, o Muay Thai é nossa ferramenta, o amor é nossa motivação e Jesus Cristo é o fundamento da nossa missão.

**Nossa essência:**

- 🥊 Esporte como ferramenta de desenvolvimento.
- ❤️ Amor, acolhimento e respeito ao próximo.
- ✝️ Fé e princípios cristãos.
- 🤝 Disciplina, responsabilidade e perseverança.

---

## 🌐 Sobre o site

O site foi desenvolvido para oferecer ao Jai Rak Team uma presença digital moderna, acessível e profissional.

O objetivo é reunir as principais informações do projeto em um único lugar, facilitando a participação de novos alunos, o contato com a equipe e o apoio à iniciativa.

A solução foi pensada para atender às necessidades atuais do projeto, priorizando simplicidade, desempenho e facilidade de manutenção.

### Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| Página institucional | Apresentação do Jai Rak Team e de sua história e propósito. |
| Nossa missão | Apresentação dos valores esportivos, sociais e cristãos. |
| Equipe | Informações sobre os responsáveis pelo projeto. |
| Galeria | Exibição de fotografias reais das atividades. |
| Participação | Contato direto pelo WhatsApp para informações sobre inscrições. |
| Doações | Interface de contribuição com QR Code Pix e chave copiável. |
| Parcerias | Canal de contato para possíveis apoiadores e patrocinadores. |
| Redes sociais | Integração por links com os canais oficiais do projeto. |
| Design responsivo | Interface adaptada para computadores, tablets e celulares. |

### 💛 Sistema de doações simplificado

A área de doações foi projetada para oferecer uma experiência intuitiva, sem a necessidade de um sistema financeiro complexo.

O visitante pode selecionar um valor de referência, visualizar o QR Code Pix oficial ou copiar a chave Pix para realizar a contribuição em seu aplicativo bancário.

O pagamento é realizado externamente, por meio do Pix.

O site não processa transações financeiras, não armazena dados bancários e não confirma pagamentos automaticamente.

## 🛠️ Desenvolvimento

O desenvolvimento do site foi iniciado com o Lovable e continuado no Visual Studio Code, com apoio do Claude na análise, implementação e refinamento do código.

A aplicação foi estruturada como uma landing page institucional, evitando funcionalidades desnecessárias para a fase atual do projeto.

A arquitetura prioriza componentes reutilizáveis, organização do código e facilidade de evolução.

### Executando localmente

Clone este repositório:

    git clone URL_DO_REPOSITORIO

Acesse a pasta do projeto:

    cd NOME_DA_PASTA

Instale as dependências utilizando o gerenciador de pacotes configurado no repositório.

Para projetos configurados com npm:

    npm install

Inicie o ambiente de desenvolvimento, caso o script `dev` esteja disponível:

    npm run dev

Abra no navegador o endereço exibido no terminal.

**Observação:** utilize os scripts e o gerenciador de pacotes definidos no `package.json` e no lockfile do projeto.

## 📱 Experiência do usuário

O site foi pensado especialmente para acessos provenientes de dispositivos móveis, considerando que a divulgação do projeto ocorre principalmente pelo Instagram, WhatsApp e materiais com QR Code.

A navegação permite que o visitante encontre rapidamente as informações mais importantes e entre em contato com a equipe sem precisar criar uma conta ou preencher formulários extensos.

Os principais caminhos de interação direcionam o usuário ao WhatsApp oficial ou à seção de contribuições via Pix.

## 🚀 Evolução do projeto
