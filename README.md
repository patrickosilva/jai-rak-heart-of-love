## 1. MISSÃO DO PROJETO

Crie um site institucional completo, moderno, profissional, responsivo e visualmente impactante para o projeto social de Muay Thai chamado **JAI RAK TEAM**.

Não entregue um protótipo incompleto. Desenvolva um site real, com todos os elementos funcionais e preparado para publicação.
